📖 Description
A smart and interactive task management system designed to enhance productivity by integrating gamification elements such as rewards, levels, streaks, and achievements. The system helps users efficiently organize tasks while staying motivated through engaging and game-like experiences.

🎯 Objective
To improve user productivity and consistency in completing daily tasks by combining traditional task management with motivational game mechanics.

🚀 Key Features
    ✅ Task Creation & Management
    Create, update, delete, and prioritize     tasks with deadlines and categories.
   🎮 Gamification System
   Points awarded for completing tasks
   Level progression based on productivity
   Achievement badges for milestones
   Daily/weekly streak tracking
   
📊 Progress Tracking Dashboard
Visual insights into completed tasks, productivity trends, and performance.

⏰ Reminders & Notifications
Smart alerts to ensure timely task completion.

🔥 Streak & Consistency System
Encourages daily engagement and habit building.

🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: python flask
Database: SQLITE

Version Control: Git & GitHub
💡 Unique Selling Points
Combines productivity + gamification to reduce procrastination
Enhances user engagement compared to traditional task managers
Scalable design for adding AI-based personalization features

📈 Future Enhancements
AI-powered smart scheduling
Social features (leaderboards, sharing achievements)
Mobile app integration
Integration with calendars and productivity tools

🧪 Use Case
Ideal for students, professionals, and anyone looking to build habits and manage tasks effectively in a fun and engaging way.
